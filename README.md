# CS230---Operating-Platforms

## **Danny Fetter - CS230 - Portfolio Journal**

Working on the fictional game, Draw It or Lose It, for the Gaming Room taught me a lot about RESTful APIs, dropwizard/jersey setup on VScode, and the value of intelligent architectural design patterns in code. The client-server concept, paired with the singleton and the iterator patterns, made this project's code execute smoothly. I am particularly proud of my inclusion of the ETL (Extract Transform Load) pattern idea for the image transfer, and the idea of the user having an option to download the images to their own client-end devices, as well. I found the process of reviewing the diagram most helpful because it helped me visualize the way the system was meant to connect with each important part. I interpreted the needs of the client in a way that I tried to approach the problem from the perspective of a small business/startup with big goals and a small budget respected. I wanted to prioritize the most efficient and optimized path that also did not "break the bank" or required the development team to "re-invent the wheel." The best way to optimize a system, in my eyes, is often to develop the simplest solution so that it scales with grace and not with added complexity. When setting up the dropwizard setup for the first time on. VScode, I first followed along with the eclipse tutorial, but it took more time than I expected to translate to my preferred software (VScode). After a long day of trial, error, debugging, and research, I finally finished the dropwizard tutorial all through VScode. After that, implementing the changes to my project code to include correct API usage was much easier, and I felt particularly proud of the work I had done.
